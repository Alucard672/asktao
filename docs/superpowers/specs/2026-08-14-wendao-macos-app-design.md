# 问道前台助手 macOS 应用设计

## 目标

把现有 `wendao-bot` 命令行工具打包为可双击启动的独立 macOS 应用 `问道前台助手.app`。用户无需打开终端或单独安装 Python。应用默认进入只观察模式，任何点击仍必须通过现有窗口身份、固定尺寸、识别置信度、安全状态和点击后转换校验。

首个版本仍只控制一个标题唯一、完全可见、尺寸固定的主号窗口，不增加双开或后台操作能力。

## 方案

采用轻量桌面控制窗口，并用 PyInstaller 生成 `.app`。GUI 只负责展示状态、收集配置和向现有编排器发送控制请求；识别、规划、安全授权、点击、存储和通知继续复用现有模块，避免形成第二套自动化逻辑。

打包结果包括：

- `dist/问道前台助手.app`
- 一个便于复制或传输的 ZIP 包
- 应用内置默认配置、模板目录及所需 Python/macOS 框架依赖

应用不签名、不公证的本地开发版本可能触发 Gatekeeper 提示。签名和公证不属于首个版本范围，但打包文档会说明本机打开方式。

## 界面与状态

主窗口包含：

- 游戏窗口连接状态，包括标题和检测到的固定尺寸；
- 当前页面状态、识别置信度和已识别目标名称；
- 当前运行状态和最近一次暂停原因；
- “只观察”“单步运行”“连续运行”“暂停”“恢复”“停止”按钮；
- 本地配置文件选择入口和运行数据目录入口；
- iMessage 暂停通知预览入口。

界面不显示或记录 OCR 原文、聊天内容及通知收件人等敏感信息。日志继续使用现有脱敏事件格式。

## 启动与控制流程

1. 双击应用后加载配置并检查屏幕录制权限、游戏窗口标题、进程身份及尺寸。
2. 应用自动进入只观察模式，不点击游戏。
3. 若检测到实际尺寸与配置不一致，停止识别流程并提示选择配置；不会自动放宽尺寸校验。
4. 只有在当前尺寸已有可用模板、观察证据合格时，才允许用户启动单步运行。
5. 单步运行仍执行完整 30 秒预检，通过后最多点击一次。
6. 连续运行默认锁定；至少完成一次成功的单步运行后，本次应用会话内才解锁。
7. 暂停、停止、系统信号或应用退出都会在下一次输入前设置共享停止状态。

应用首次检测到当前 919×674 窗口时可以创建对应自定义配置，但不会自动制造识别模板。该尺寸的真实正向模板仍需从用户监督的画面中采集和复核。

## 安全与异常处理

GUI 不得直接调用鼠标事件。所有动作必须进入现有 `Orchestrator`、`SafetyGuard` 和 `GameSession` 流程。

出现以下任一情况时暂停且不重试点击：

- 付费、验证码、选择题、死亡、背包满或断线；
- 未知页面、低置信度或 OCR/模板证据不足；
- 游戏窗口身份、尺寸、位置或前台遮挡校验失败；
- 点击后未在限定检查次数内进入允许的后继状态；
- 用户按下暂停、停止或退出应用。

iMessage 默认仅预览。真实测试发送继续要求用户在发送前确认完整收件人和正文，并由 macOS 授予 Messages 自动化权限。

## 组件边界

- `app.py`：应用入口和生命周期，不包含识别或点击规则。
- GUI 控制器：把后台运行状态转换为界面模型，把按钮操作转换为编排器控制事件。
- 后台工作线程：运行观察或自动化循环，避免阻塞主界面；通过线程安全队列上报脱敏状态。
- 现有核心模块：保持为唯一的识别、规划、安全、点击、存储和通知实现。
- 打包配置：收集默认 YAML、模板资源、图标及 PyObjC/OpenCV 依赖。

后台线程不能直接更新 GUI；主线程定期消费状态队列。关闭窗口时先设置停止事件、等待后台线程退出，再结束应用。

## 测试与验收

自动化测试至少覆盖：

- 双击入口启动后默认进入只观察模式；
- 未通过模板、权限、窗口或尺寸检查时运行按钮保持禁用；
- 单步运行完整执行 30 秒预检且最多点击一次；
- 连续运行在成功单步前不可用；
- 暂停、恢复、停止和关闭窗口不会产生额外点击；
- 状态面板不泄露 OCR 原文、聊天内容或通知收件人；
- PyInstaller 构建包含配置、模板及运行依赖；
- 从构建出的 `.app` 启动能找到内置资源。

离线测试通过后，仍需在用户监督下完成：屏幕录制权限验证、919×674 正向模板采集、30 秒观察、一次单步点击、辅助功能权限和（另行确认后）iMessage 真实发送测试。未完成这些步骤前，不宣称应用可以安全连续挂机。

## 非目标

- 双开或多开；
- 后台点击、最小化运行或遮挡运行；
- 自动处理付费、验证码、答题、死亡、背包满或断线；
- 绕过游戏规则、反作弊、权限提示或 macOS 安全机制；
- Developer ID 签名、Apple 公证或 App Store 发布。
